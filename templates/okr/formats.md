# OKR 模板与诊断对照

## 标准 OKR 模板

```markdown
# 「周期」「个人/团队」OKR

## O1：「定性目标，有野心，≤20字」
- KR1：「基线值」→「目标值」（衡量口径：「」）
- KR2：「基线值」→「目标值」
- KR3：「基线值」→「目标值」
- 对齐：支撑「上级/公司」的「O几」

## O2：「」
- KR1-3（同上）
```

## 诊断对照：常见错误改写

### 错误 1：KR 是任务不是结果

| 原稿 | 问题 | 改写 |
|---|---|---|
| KR1：上线会员体系 | 上线了不等于有价值 | KR1：会员体系上线 3 个月内，付费会员从 0 达到 5,000 人 |
| KR2：每周发一篇公众号 | 是任务量，不是结果 | KR2：公众号平均单篇阅读从 2,000 提升到 8,000 |

### 错误 2：不可衡量

| 原稿 | 问题 | 改写 |
|---|---|---|
| KR：大幅提升客户满意度 | 无口径无数字 | KR：客户 NPS 从 32 提升到 45（季度末调研口径） |
| O：让团队更强 | 无法裁决 | O：打造能独立作战的前端小组（KR 用交付例证衡量） |

### 错误 3：O 里掺数字 / KR 太多

- O 出现"提升 30%" → 数字挪到 KR，O 改为方向描述
- 一个 O 挂 8 条 KR → 砍到 3-5 条：只留周期结束裁决得了的

### 错误 4：日常工作混入

- "按时参加周会""及时响应需求" → 删除，写进岗位职责任务清单，不进 OKR

## 撰写模式：三级野心示例（以"提升会员收入"方向为例）

- 稳妥 O：会员收入稳步增长（KR：季度会员收入 80 万 → 100 万）
- 进取 O：把会员做成公司第二收入曲线（KR：付费会员 5,000 → 20,000；续费率 40% → 55%）
- 挑战 O：重新定义行业的会员服务标准（KR：发布行业首个会员服务白皮书；NPS 行业第一）

标注清楚：挑战档达成率可能只有 60-70%，需用户自选。
