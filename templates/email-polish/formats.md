# 四种语气模板

润色时套用对应语气的称谓、开头、结尾惯例。正文按 SKILL.md 第三步规则处理。

## 语气一：正式商务（对上级/客户/外部）

- 称谓：「X 总/X 经理」或「尊敬的 X 女士/先生」
- 开头：「您好。就「事项」，向您汇报/致函如下：」
- 结尾：「期待您的回复。祝工作顺利。」或「如需进一步说明，我随时可以配合。」
- 署名：姓名 + 部门 + 联系方式（用户给什么用什么，不虚构）

## 语气二：平级沟通（同事协作）

- 称谓：「X 哥/X 姐/名字」
- 开头：「Hi X，关于「事项」：」
- 结尾：「麻烦啦」/「辛苦同步一声」
- 特点：可直接，但行动项和期限仍要写清楚

## 语气三：友好催办（追回复/追事项）

结构固定为四步，全程不指责：

```markdown
「称呼」，

「一句事实：当时约定/上次提到的事和时间」
「一句现状：目前尚未收到/还未确认」
「一句影响+提醒：这件事影响「 downstream 事项」，麻烦您「具体行动」」
「一句出口：如果时间上有困难，我们可以「替代方案」，您看哪种方便」
```

示例骨架：
> 王经理，您好。上周三我们约定本周一前确认验收单，目前还没有收到反馈。因为付款流程卡在这一步，麻烦您明天下班前回复确认结果。如果单据本身有问题，也可以先电话沟通，我们尽快配合修改。

## 语气四：道歉澄清（出问题/纠正误解）

结构固定为四步：

```markdown
1. 「直接认事：xx 出了什么问题/造成什么不便，不找借口」
2. 「一句原因（只陈述事实，不推责）」
3. 「已采取的措施 + 时间点」
4. 「后续承诺 + 补偿/替代方案（如有）」
```

注意：澄清误解时先复述对方的理解（"关于您提到的 xx"），再给出事实差异，避免"您误会了"这类表述。

## 中英改写对照要点

| 中文习惯 | 英文惯例 |
|---|---|
| "在百忙之中打扰您了" | 直接进入主题 "I'm writing to..." |
| "望周知/望采纳" | "Please let me know if you have any questions." |
| 客套铺垫两三段 | 第一句说明来意 |
| "尽快回复" | 具体期限 "by this Friday" |

英文署名惯例：Best regards / Thanks + 名字。时态、单复数、冠词按英文习惯整体校对。
