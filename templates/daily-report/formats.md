# 三种日报格式模板

占位符用「」，输出时替换为真实内容。某段为空则整段省略。

## 格式一：简洁三段式（默认，IM/邮件通用）

```markdown
【日报】「姓名」MM-DD
✅ 今日完成
1. 「动作+对象+进度/数据」
2. 「动作+对象+进度/数据」
🔄 进行中
- 「事项」：「当前进度」，预计「时间」完成
📌 明日
1. 「可验收动作」
```

## 格式二：钉钉/企业微信日志式

```markdown
「今日工作」
1. 「动作+对象+进度/数据」
「明日计划」
1. 「可验收动作」
「需协调」
- 「事项」+「需要谁做什么」（无则省略整段）
```

钉钉日志正文不要用 emoji 和加粗符号（系统模板不渲染），纯文本即可。

## 格式三：邮件日报（单独发给上级）

```markdown
主题：【日报】「姓名」MM-DD

「称呼」好，

今日进展：
1. 「动作+对象+结果/进度」（最多 5 条）

进行中：
- 「事项+进度+预计完成时间」

明日安排：
1. 「可验收动作」

「需要决策/支持的事项，无则删」
```

## 格式映射速查

| 用户场景词 | 格式 |
|---|---|
| 日报/今日总结（未说明渠道） | 简洁三段式 |
| 钉钉日志/企业微信日报 | 对应系统格式 |
| 发邮件给领导/单独汇报 | 邮件日报 |
