# 示例：零散输入 → 日报

## 输入（用户原话）

> 上午把周报改完了交了，下午一直在弄那个数据导出的 bug，还差一点，估计明天上午能好。

## 输出（简洁三段式）

【日报】张三 10-09
✅ 今日完成
1. 修订周报并提交
🔄 进行中
- 修复数据导出 bug：已定位原因，完成 80%，预计明日 12:00 前修复
📌 明日
1. 完成数据导出 bug 修复并回归验证

## 常见错误对照

| 错误写法 | 问题 | 正确写法 |
|---|---|---|
| 上午改了周报 | 缺结果 | 修订周报并提交 |
| 弄 bug | 无对象无进度 | 修复数据导出 bug，完成 80% |
| 明天继续 | 不可验收 | 明日 12:00 前完成修复并回归验证 |
| 一直在开会 | 过程无产出 | 删除，或提炼会议结论归入相关事项 |

## 降级规则

用户只给一句"在修 bug"时：写"修复 xx bug（进行中）"并追问一句"bug 影响哪个功能？"，用户不答就保持占位"【待补充：影响范围】"，不编造。
