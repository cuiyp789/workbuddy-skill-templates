# 示例：乱转写 → 好纪要

## 输入（转写节选，口语、无归属、有跑题）

> 呃那个新版首页啊，老板说还是要改，太花了。然后小李说他那边接口下周能好，最晚周五吧。对了今天食堂的糖醋排骨绝了。再就是测试环境老是挂，王强你修一下，这个月底前必须稳定。预算的事先不定了，财务那边数据还没出来，下次再说。

## 分析

- "老板说还是要改，太花了" → 决议：首页改版获管理层确认，方向去花哨
- "小李接口最晚周五" → 行动项：负责人小李、事项明确、截止时间"下周五"
- "糖醋排骨" → 跑题，删除
- "王强修测试环境，月底前稳定" → 行动项：负责人王强、截止"月底"
- "预算先不定…下次再说" → 待定问题：预算决策延后，原因"财务数据未出"

## 输出（行动项清单格式）

【新版首页评审会行动项】待补日期
1. 首页改版按"去花哨"方向执行——设计组，待补排期
2. 交付新版首页依赖接口——小李，下周五
3. 修复测试环境不稳定问题——王强，本月底
❓待确认
- 预算方案——财务数据未出，下次会议再议

## 常见错误对照

| 错误写法 | 问题 | 正确写法 |
|---|---|---|
| 大家讨论了首页的事情 | 无结论无归属 | 决定：首页按"去花哨"方向改版（老板确认） |
| 小李会弄好接口的 | 无截止时间 | 接口交付——小李，下周五 |
| 有人提到测试环境有问题 | 责任人丢失 | 修复测试环境——王强，本月底 |
| 会议氛围良好，大家吃了糖醋排骨 | 流水账 | 删除 |
| 预算定为 50 万 | 编造决议 | 待定：预算待财务数据（下次会议） |

## 追问模板（最多一轮，缺什么问什么）

- 基础信息："会议主题和日期方便补一下吗？参会人有哪几位？"
- 归属："『月底前稳定』这条是王强认领的吗？"
- 决议："预算这事最后定了吗，还是下次再议？"

用户答不上的项直接用【待确认】占位，不要追问第二轮。
