# 四种场景结构模板

逐页大纲的章节骨架。占位符用「」，实际输出替换为真实内容或【待补充】。

## 场景一：工作汇报（结论先行金字塔，默认 8-10 页）

```markdown
P1 封面：「汇报主题」+一句话核心结论
P2 结论总览：3 个分论点各一行（先说结论）
P3-P4 分论点 1：「结论式标题」/ 数据支撑 / 可视化：柱状图对比
P5-P6 分论点 2：「结论式标题」/ 可视化：时间线
P7 分论点 3：「结论式标题」/ 可视化：大数字单页
P8 风险与求助：「卡点」+「需要的支持」（必放，评委最关心）
P9 下一步：3 条可验收计划
P10 结尾：结论回顾 + 期望的决策/行动
```

## 场景二：项目提案（问题-方案-收益，8-10 页）

```markdown
P1 封面：提案一句话
P2 问题现状：用数据把问题量化
P3 问题影响：不解决会怎样（损失/机会成本）
P4 方案总览：一页说清方案全貌（可视化：架构图/流程图）
P5 方案细节：关键设计 2-3 点
P6 收益预测：量化收益（可视化：对比柱状图）
P7 成本与周期：投入、里程碑时间线
P8 风险与应对：2-3 条
P9 需要的决策：明确请听众拍板的事项（必放）
```

## 场景三：培训分享（认知-演示-练习）

```markdown
P1 封面：课程一句话（学完你会什么）
P2 为什么重要：应用场景/痛点
P3 核心概念：是什么（可视化：示意图）
P4-P6 方法/步骤：每页一个要点+示例
P7 完整案例演示：从 0 到 1 过程
P8 常见坑：3 条
P9 总结：知识卡片式回顾
P10 练习/行动：听众课后做的一件事
```

## 场景四：年终汇报（回顾-亮点-规划，10-12 页）

```markdown
P1 封面：年度一句话
P2 全年结论：目标达成总览（可视化：目标 vs 实际表格）
P3-P5 年度亮点 3 件：每页一件，数据压轴
P6 常规工作：一页合并带过
P7 不足与改进：1-2 条，各配改进动作
P8-P9 明年规划：目标+关键举措
P10 结尾：致谢+期望支持
```

## 通用检查清单

- 页标题是否都是结论句（没有"xx 情况介绍"式名词页）？
- 每页要点是否 ≤3 条？
- 数据页是否注明来源和基准？
- 是否有明确的"需要对方做什么"？
- 总页数是否匹配时长（10 分钟 ≈ 8-10 页）？
